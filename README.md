# A Parent's Guide to USD 353

Independent parent resource for Wellington, Kansas families. Not an official USD 353 site.

Live site: https://usd353parents.netlify.app

- `index.html` – the whole site
- `meetings.json` – board meeting minutes and video links (updated weekly by a scheduled task)
- `docs/` – 2026–27 handbooks, the 2025–26 negotiated agreement, and `kb.json` (handbook text used by the "Ask a question" box)
- `preview.png` – link preview image
